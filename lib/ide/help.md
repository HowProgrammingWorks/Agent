# hotkeys

`🧠` or `?` this screen · `esc` close

## global

- `tab` cycle tree / editor / terminal / agent
- click a pane to focus it; click a file to open it
- click `🧠` help
- `f10` or click `✕` quit
- `ctrl+b` show or hide the file tree
- `ctrl+space` show or hide the terminal
- `ctrl+l` insert a `file/line:col` ref into chat
- `ctrl+c` copy in editor or chat; quit elsewhere
- `ctrl+v` paste in editor or chat

## editor

- `esc` close this screen
- `l` line numbers (help / binary / truncated)
- arrows / `pgup` / `pgdn` / `home` / `end` move
- `ctrl+home` / `ctrl+end` file start / end
- `shift+arrows` select · drag to copy
- `ctrl+z` undo · `ctrl+shift+z` redo

## tree

- `enter` open · `/` search

## terminal

- `enter` run · up / down history · `pgup` / `pgdn` scroll

## agent

- `enter` send · `alt+enter` newline · `esc` clear
- `y` / `n` approve or deny a tool call
